# 지역 확인 필요 사례 (2026-10-02 기준 3건)

`scripts/pc_cases.py scan` 이 메모의 지역으로 시·군·구를 정할 수 없어 건너뛰는 사례입니다. 원본은 운영자 PC의
`폐차사진원본` 폴더에 그대로 있고(반영됨.txt 없음), 이 저장소에는 사진도 메모도 올라가지 않았습니다.

고치는 방법: 확인된 지역을 `data/case_region_fixes.json` 에 한 줄 추가합니다(원본 메모는 고치지 않음).
`{"folder": "우선/<원본 폴더 이름>", "region": "대전광역시 서구", "confirmed": "날짜 누가 확인"}`
동까지 알면 동까지 적고(동 페이지 규칙), 구까지만 알면 구까지만 적습니다(구 페이지에만 붙음).
그러면 다음 PC 사례 가져오기 때 자동으로 대상이 됩니다. 추가한 건은 이 목록에서 지웁니다.
