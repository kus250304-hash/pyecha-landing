# 사례 올리는 방법

> 평소에는 PC의 Claude 앱 예약 작업이 `폐차사진원본\우선`·`일반` 폴더에서 하루 3건을 골라 가리고 줄여서 이 폴더에 올립니다(`docs/pc-case-import-prompt.md`, `scripts/pc_cases.py`). 아래는 이 폴더에 직접 넣을 때의 형식입니다.

이 폴더(`cases/input/`)에 **사례 하나당 폴더 하나**를 올려 두면, 매일 돌아가는 자동 작업이 사례 페이지를 만들고 해당 지역 페이지에 카드로 붙입니다. 처리가 끝난 폴더는 `cases/done/` 으로 옮겨집니다.

## 폴더 안에 넣을 것

```
cases/input/2026-09-24-역삼동-그랜저/     ← 폴더 이름은 자유 (날짜로 시작하면 그 날짜를 씀)
  메모.txt                                 ← 아래 형식
  1.jpg  2.jpg  3.jpg                      ← 번호판·얼굴·서류를 가린 사진 (jpg/png/webp)
```

## 메모.txt 형식

```
지역: 서울특별시 강남구 역삼동
차종: 2012년식 그랜저
날짜: 2026-09-20
상황: 지하주차장에 3년 넘게 세워 둔 차로 시동이 걸리지 않았고, 등록증은 분실한 상태였습니다.
처리: 등록원부로 압류 없는 것을 확인한 뒤 수출 비교매입으로 진행했습니다. 견인차가 지하 2층까지 내려가 당일 인수했습니다.
결과: 서류는 협력업체가 대신 처리해 이틀 뒤 말소까지 끝났습니다.
한마디: 전화 한 통으로 다 끝나서 편했습니다.
```

- **꼭 써야 하는 것**: 지역, 차종, 상황, 처리 — 또는 PC 원본 메모 형식인 지역, 차종, 연식, 시동(아래)
- PC 원본 메모 형식도 그대로 읽습니다. 표에 없는 칸(고객명·연락처 등)은 읽지 않고 버립니다. `실제 진행`은 글에 쓰지 않습니다.

```
날짜: 2022-12-16
지역: 용인시 처인구 모현읍
차종: 그랜드스타렉스 (사진)
연식: 2008
시동 여부: 시동됨
운행 가능 여부: 확인필요
상황: 일반폐차
실제 진행: 일반폐차
```
  → 사례 글: "차량 정보: 차종 그랜드스타렉스 · 연식 2008년식 · 시동 걸림 · 운행 현장 확인 필요 · 문의 내용 일반폐차", "2008년식 그랜드스타렉스 차량으로, 시동은 걸리는 상태였습니다. 운행 가능 여부는 현장에서 확인이 필요했습니다."
- `지역`은 시도를 빼도 한 곳으로 정해지면 됩니다(`용인시 처인구 모현읍`). 옛 이름(광주광역시·전라남도·인천 중구, ○○면→○○읍)도 새 이름으로 찾습니다. 여러 곳과 맞으면 건너뜁니다.
- `날짜: 미상` 이면 사례 페이지에 날짜를 표시하지 않습니다.
- 동을 모르면 `지역: 충청북도 충주시`, `지역: 대구광역시 중구` 처럼 시·군·구까지만 적어도 됩니다(한 곳으로 정해질 때). 이 사례는 동 페이지에는 붙지 않고 **그 구 페이지(/gu/)에만** 붙습니다. 구 페이지가 아직 없으면 이 폴더에 그대로 남아 "대기"로 표시되고, 구 페이지가 생기면 다음 실행 때 자동으로 처리됩니다. 시·도만(`서울`) 있거나 여러 구와 맞으면(`수원시`) 건너뜁니다.
- **선택**: 날짜(없으면 폴더 이름의 날짜, 그것도 없으면 처리한 날), 결과, 한마디
- **주의(2026-10-09)**: `상황` 칸에 "일반폐차"·"차령초과말소"·"조기폐차"·"수출" 낱말이 들어가면 그 칸 전체가 정해 둔 짧은 문구로 바뀝니다(PC 원본 메모용 규칙). 사연을 길게 쓸 때 "수출" 이야기는 `처리` 칸에 쓰세요.
- **유튜브 영상(선택, 여러 줄 가능, 2026-10-08)**: `youtube: <주소> <짧은 설명>` 한 줄에 영상 하나. 롱폼(youtu.be/…, youtube.com/watch?v=…)과 쇼츠(youtube.com/shorts/…) 모두 됩니다. 사례 페이지 본문 "영상으로 보기"에 영상과 유튜브 링크가 들어갑니다. 설명에도 금액·결과 약속·수출 단정을 쓰지 않습니다.
  - 영상이 있으면 **사진 없이** 올려도 됩니다(사진 칸은 빠지고, 카드에는 사진 없이 표시, 공유 이미지는 첫 영상의 유튜브 썸네일).
```
youtube: https://youtu.be/AyCMkIrc2_U 이 차 폐차 진행 영상
youtube: https://youtube.com/shorts/0cH-t9saQ6k 트렁크 사고차, 수출 될까요?
```
- `지역`은 `시도 시군구 동`을 정식 이름으로 씁니다. 예: `부산광역시 해운대구 우동`, `세종특별자치시 반곡동`(세종은 시군구 없음), `전북특별자치도 전주시 완산구 풍남동1가`
- 값이 길면 여러 줄로 이어 써도 됩니다.

## 쓰면 안 되는 것 (있으면 그 사례는 처리되지 않고 이유가 출력됩니다)

- **금액·시세**: "80만원", "시세", "견적가", "매입가" 같은 표현
- **결과를 약속하는 말**: "보장", "무조건", "100%", "1위", "최저가"
- 번호판·얼굴·서류가 보이는 사진 (스크립트가 확인하지 못하므로 올리기 전에 직접 가려 주세요)
- **"수출 된다/안 된다" 단정**: "수출 가능", "수출 불가", "수출 안 됨" 같은 표현
- **고객 정보**: 전화번호, 차량번호(12가3456), 번지·아파트 동호수·도로명 번호
- 사진 7장 이상 (6장까지)

## 사진

- 긴 변 1200px 로 줄이고, 사진 속 숨은 정보(촬영 시각·기기·GPS 위치 등 EXIF/XMP)를 **전부 지운** 새 파일로 `cases/images/` 에 저장됩니다. 저장 후 숨은 정보가 남아 있으면 처리를 중단하고, 검사(`check_pages.py`)에서도 오류로 잡습니다. 원본 크기는 상관없지만 한 장에 5MB 이하를 권합니다.
- 첫 번째 사진(이름순)이 지역 페이지 카드의 대표 사진이 됩니다.

## 만들어지는 것

- `cases/<사례 주소>.html` — 사례 페이지 (사진, 상황·진행·결과, 전화 버튼, 해당 동 상담 페이지 링크)
- `cases/index.json` — 사례 목록 (자동 관리, 손대지 않음)
- 지역 페이지의 "사례" 칸에 카드로 표시됩니다. 카드마다 "○○구 ○○동 작업 사례"처럼 실제 지역이 붙습니다.
  - 그 동 페이지에는 항상 보입니다.
  - 그 밖에는 **같은 시군구(세종은 시 전체)의 다른 동 페이지 최대 5곳**에만 보입니다. 다른 시군구·시도 페이지에는 나오지 않습니다.
  - 5라는 숫자는 `data/site_config.json` 의 `cases_extra_pages_per_case` 로 바꿀 수 있습니다.
  - 처리 결과에 "지역 페이지 N곳에 표시"로 어디에 붙었는지 출력됩니다.
  - 동 없는 사례는 그 구 페이지에만 보입니다(위 `지역` 설명).

직접 돌려 보려면: `python3 scripts/build_cases.py`

지역을 시·군·구까지 정할 수 없어 가져오지 못한 사례는 `지역-확인-필요.md` 에 적어 둡니다.
