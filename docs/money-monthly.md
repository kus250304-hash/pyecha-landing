# 월 숫자 (`data/money_monthly.json`) 칸 설명

2026-11-05 병한님 결정(상자 B-1 3번). 매달 17일 자동 보고가 "건당 평균 구간"과 "이달 안 된 이유 1위"를 말할 때 읽는 재료입니다.

- 만드는 곳: `scripts/money_monthly.py --write` — PC 예약 작업 "폐차 사례 가져오기"(오후 1시 40분) 2-1 단계가 매일 돌립니다. 거래 기록부는 운영자 PC 에만 있어 클라우드 루틴은 만들 수 없습니다. 손으로 고치지 않습니다.
- **돈 절대값(남는 돈 합계·건당 평균 만원)은 저장소에 넣지 않습니다.** 같은 스크립트가 위키 노트 `병한-업무위키\폐차\거래기록부\월 숫자.md` 표에만 적습니다. 공개 저장소에는 아래 칸만 있습니다.
- 이름·전화·차번호·개별 금액·폐차장 이름은 어디에도 없습니다.

| 칸 | 뜻 |
|---|---|
| `months` 의 키 | 달(YYYY-MM). 거래 기록부 "날짜"(문의일) 칸의 달 |
| `deals` | 거래 수 = 거래상태 "완료" |
| `lost` | 안 된 수 = 거래상태 "종료" |
| `lost_reasons` | 안 된 이유 상위 3 `[이유, 건수]`. 기록부에 "안된이유" 칸이 있으면 그 값, 없으면 메모 낱말로 가름: 금액 / 다른 데서 먼저 / 서류·명의 / 연락 끊김 / 거리·탁송 / 기타 |
| `avg_band` | 건당 남는 돈(판매가 − 매입가 − 탁송견인비)의 구간, 만원: "10 미만" / "10~40" / "40 이상" / 돈 기록이 없으면 "기록 없음" |
| `vs_last_month` | 건당 평균이 돈 기록이 있는 바로 앞 달보다 ±10% 안이면 "비슷", 위면 "올라감", 아래면 "내려감", 비교할 달이 없으면 "비교 못 함" |
| `money_n` | 판매가·매입가가 둘 다 적힌 완료 거래 수(구간을 믿을 만한지 보는 숫자) |

통화 인박스에 "안 된 이유" 칸(한 단어)이 생기면 기록부 "안된이유" 칸으로 옮겨 적는 쪽이 낱말 가름보다 정확합니다.
