답하는 법은 평소대로입니다: "ㅇ"(= 1번), "1 4 5"(여러 개), "3?"(자세히), "5x"(안 함).

- **원고를 그대로 넣지 않고 몇 곳을 고쳤습니다.** 검사 규칙과 화면에 맞추려는 것입니다: ① 한 줄 답을 "네, …"가 아니라 답 자체로 시작(예/아니요 질문이 아니라서) ② 제목 아래 한 문장을 이 페이지에 맞게 ③ 둘째 조각 제목을 "…끝나지 않는 경우가 많습니다"로 누그러뜨림 ④ 출구에 "견적서는 금액이 보이는 부분만 찍으셔도 되고" ⑤ FAQ 답 세 개를 "네 + 이유" 꼴로 ⑥ 버튼 글자는 "수리비 많이 나온 차"(맨 앞).
