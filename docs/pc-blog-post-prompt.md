# PC 예약 작업 "폐차_블로그_올리기" 지시문 (2026-11-19 병한님 "5")

블로그 초안(`docs/blog-drafts/`)을 병한님이 손으로 옮기지 않게, **PC의 Claude 앱**이 병한님 크롬(네이버 로그인된 상태)으로 하루 1편씩 폐차119 블로그에 올립니다.
클라우드 세션은 병한님 PC·네이버 계정에 들어갈 수 없어서 이 작업만은 PC에서 돌아야 합니다.

## 처음 한 번 (병한님, 5분쯤)

1. 크롬에 **Claude in Chrome** 확장이 깔려 있고 Claude 앱과 연결돼 있는지 봅니다(Claude 앱 → 설정 → 연결된 도구). 없으면 크롬 웹 스토어에서 "Claude"를 설치하고 로그인합니다.
2. 크롬에서 네이버에 로그인해 둡니다(폐차119 블로그 계정).
3. Claude 앱 → 예약 작업 → 새로 만들기 → 이름 `폐차_블로그_올리기`, 매일 **오후 7시 10분 무렵**, 아래 코드 상자를 그대로 붙여 넣습니다.
4. 첫날은 앱에서 "지금 실행"을 한 번 눌러 제대로 올라가는지 봅니다. 그 뒤로는 손대지 않습니다.

(이 작업을 만들거나 시간을 바꾸면 `docs/recovery.md` 의 Claude 앱 예약 작업 표에도 적습니다.)

## 지시문

```text
너는 폐차119 블로그(https://blog.naver.com/abh77790)에 초안 1편을 올리는 PC 예약 작업이다. 병한님께 묻지 않는다. 막히면 올리지 말고 이유만 보고한다.

[준비]
1. 저장소 폴더(pyecha-landing)에서 `git checkout main` 후 `git pull origin main`.
2. `docs/blog-drafts/posted.md` 를 읽는다(올린 글 목록: 날짜 | 초안 파일 | 글 주소). 없으면 새로 만든다.
3. 올릴 초안 하나를 고른다: docs/blog-drafts/ 아래 날짜 폴더의 .md 중 posted.md 에 없는 것, 날짜 폴더가 오래된 것부터, 같은 폴더 안에서는 파일 번호 순. 다음이면 그 초안은 건너뛰고 다음 것을 본다:
   - 맨 위 메모에 "넣기 전 확인할 것"·"확인 필요" 줄이 남아 있음
   - 메모에 "2027년에 올리면 이 문단은 빼야 함" 같은 날짜 조건이 있는데 오늘이 그 조건에 걸림
   - 본문에 금액(원·만원 숫자), "최고가·보장·100%·무료 견인", 010-9926-7779·1600-6011 말고 다른 전화번호가 있음
   올릴 것이 없으면 "올릴 초안 없음"만 보고하고 끝낸다.

[올리기 — Claude in Chrome 으로, 병한님이 로그인해 둔 크롬에서]
4. blog.naver.com/abh77790 에서 글쓰기를 연다. 로그인이 안 돼 있으면 올리지 말고 "네이버 로그인 필요"만 보고한다(비밀번호를 입력하지 않는다).
5. 제목 = 초안의 "제목 후보 1". 본문 = "==========" 아래 전부, 줄바꿈 그대로. "■" 줄은 소제목(굵게), "[인용구] …" 줄은 인용구로.
6. "[사진 1: …]" 자리에는 메모에 적힌 사진 파일(cases/images/…jpg, 번호판 가림 확인된 것)을 저장소 폴더에서 올린다. 메모에 사진이 없거나 파일이 없으면 그 줄을 지우고 사진 없이 올린다.
7. 맨 아래 해시태그 줄은 태그 칸에 넣는다(본문에는 남기지 않음). 공개 설정은 전체 공개.
8. 발행한 뒤 글 주소를 확인한다.

[기록]
9. posted.md 맨 아래에 `| YYYY-MM-DD | <초안 파일> | <글 주소> |` 한 줄을 더하고, `git add docs/blog-drafts/posted.md` → `git commit -m "Blog posted (YYYY-MM-DD)"` → `git push origin main`(거절되면 pull --rebase 후 한 번 더). 다른 파일은 넣지 않는다.

[보고]
- 첫 줄: "올림: <제목> — <글 주소>" 또는 "안 올림: <이유>"
- 건너뛴 초안과 이유
- 남은 초안 수
```
