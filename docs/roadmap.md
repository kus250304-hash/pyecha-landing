# 사이트 확장 로드맵 (3층 구조)

2026-09-29 작성. 매일 루틴은 3시 보고를 쓰기 전에 이 파일을 읽고, 아래 "조건이 되면 먼저 알릴 것"에 해당하는 항목이 있으면 보고 맨 위에 먼저 알린다.

## 1. 구조

| 층 | 폴더 | 파일 이름 | 상태 |
|---|---|---|---|
| 동 페이지 | `/pages/` | 지금 그대로 (`seoul-jongno-cheongun.html`) | 운영 중 |
| 시·군·구 페이지 | `/gu/` | 동 페이지 이름의 앞부분 (`seoul-jongno.html`, `incheon-yeonsu.html`) | 견본 1개(종로구) 확인 중 |
| 시·도 페이지 | `/si/` | 아직 만들지 않음 | 아래 조건이 되면 제안 |

- 구 페이지 제목: "○○구 폐차 | 폐차 보상금 vs 수출 시세 비교" 형식.
- 사이트맵(`sitemap.xml`)에 구 페이지도 넣고 `lastmod` 를 적는다.
- 세종특별자치시처럼 시·군·구가 없는 곳은 시 전체를 구 페이지 하나로 본다(`sejong.html`).
- 행정구역 이름이 바뀐 구(제물포구·영종구·서해구·검단구, 전남광주)는 새 이름으로 파일 이름을 만든다(`incheon-jemulpo.html`). 그 구의 옛 동 페이지 주소는 바꾸지 않는다.

## 2. 구 페이지 내용 (빈 목록 페이지 금지)

아래 다섯 덩어리를 모두 채울 수 있을 때만 만든다. (a)~(d) 중 하나라도 못 채우면 그 구는 보류하고 이유를 보고에 적는다.

- (a) 구 소개 2~3문장: 그 구의 동 페이지들에서 이미 사실 확인된 랜드마크 중 구 전체를 대표하는 것 2~3개를 골라 쓴다. 새 장소를 지어내지 않는다.
- (b) 구 안의 동 페이지 목록과 링크. 동 페이지가 3개 이상인 구만 만든다.
- (c) 그 구 손님이 자주 묻는 질문 3개. 지역 특성(아파트 지하주차장 견인, 섬·산간 견인 거리, 군부대·산업단지 등)을 반영해 구마다 다르게 쓴다.
- (d) 지역 공공 정보 표. 웹 검색으로 확인되는 줄만 넣고, 확인 안 되는 줄은 뺀다. 줄마다 출처 주소를 남긴다.
  1. 말소등록 관할 관청(차량등록사업소 또는 구청 교통과) 이름·주소
  2. 노후경유차 조기폐차 지원 안내: 해당 지자체 공고가 있으면 "○○시 환경 부서 공고 확인" 수준으로만. 금액은 쓰지 않는다.
  3. 시군구별 자동차 등록대수(공공데이터포털 또는 국토교통부 통계, 기준 연월 표기)
- (e) 상담 안내: 대표번호 1600-6011, "폐차 전에 수출과 비교해서 유리한 쪽으로". 금액·결과 단정 금지, "상담 후 확인" 표현.

## 3. 동 페이지 연결

- 모든 동 페이지 위쪽에 "서울 › 종로구 › 청운동" 길 안내 줄을 넣는다. 구 이름은 그 구 페이지가 있으면 링크, 없으면 글자만.
- 구 페이지가 새로 생기면 그 구의 동 페이지를 다시 렌더링해 링크가 걸리게 한다.

## 4. 문장 틀 여러 벌 (복사본 방지)

- 동·구 페이지의 소개문, FAQ 답변(공통 FAQ), 마무리 문단을 각각 5가지 이상 버전으로 두고 페이지마다 다른 조합을 쓴다.
- 같은 구 안의 동 페이지끼리는 같은 조합이 나오지 않게 한다(빌더가 자동 배정).
- 뜻은 같아도 되지만 문장 구조·순서·어휘가 달라야 한다.

## 5. 새 동 페이지 규칙 (2026-09-29부터 적용)

- 랜드마크: 그 동 안에 있다고 웹 검색으로 확인되는 장소가 없으면 도로명을 쓰지 않고, 그 동은 보류하고 다음 후보로 넘어간다. 도로명 랜드마크는 금지(`fact_check.py` 가 막음).
- "○가"로 끝나는 법정동(종로1가~6가 등)은 따로 만들지 않고 한 페이지(예: "종로")로 묶어 안에 "종로1가~6가"라고 적는다. 이미 있는 ○가 페이지 38개는 그대로 둔다.
- 사람이 거의 살지 않는 법정동(산업단지·산지·인구 극소)은 건너뛴다(보류, 이유에 판단 근거를 적음).
- 우선순위(동·구 페이지 모두, 2026-09-29 변경): **시군구별 차령 10년 이상 노후차 등록대수가 많은 구부터**.
  - 통계는 `data/vehicle_stats.json`(노후차), 없으면 `data/vehicle_stats_total.json`(전체 등록대수) 순. 넣는 방법은 `scripts/vehicle_stats.py` 맨 위 설명.
  - 둘 다 없으면 임시로 "구 페이지가 있는 구 → 동 페이지가 많은 구" 순으로 뽑고, 3시 보고에 "등록대수 통계 없음"을 알린다.
  - 통계 출처: 국토교통부 통계누리(stat.molit.go.kr) 자동차등록현황보고, 공공데이터포털(data.go.kr) 자동차 등록 현황. 숫자를 지어내거나 추정하지 않는다.
  - 2026-09-29 현재: 이 작업 환경의 네트워크 설정이 data.go.kr·stat.molit.go.kr·kosis.kr 접속을 막아 통계를 받지 못함 → 임시 순서로 운영 중.

## 6. 속도와 보고

- 매일 루틴: 동 페이지는 지금처럼(`daily_count`) + 구 페이지 5개(노후차 등록대수가 많은 구부터, 통계가 없으면 동 페이지가 많은 구부터). **구 페이지는 종로구 견본을 병한님이 승인한 뒤부터 루틴에 넣는다.**
- 3시 보고에 매일 적을 것: 오늘 만든 구 페이지 목록, 공공 정보 중 확인 못 해서 뺀 항목, 보류한 구와 이유, 동 페이지 총 개수.

## 7. 조건이 되면 먼저 알릴 것 (3시 보고 맨 위)

| 조건 | 할 일 |
|---|---|
| 구 페이지가 처음 생긴 지 2주 이상 지났거나 60개를 넘음 | 시·도 페이지 16개(`/si/`) 만들기를 제안 |
| 위키에 폐차 거래 기록부가 생김 | 기록(동, 차종, 연식, 폐차/수출, 손님 한마디)을 그 동·구 페이지 사례로 자동 반영하는 단계를 제안. 금액은 절대 쓰지 않음 |
| 네이버 등록 상황 확인됨 | 기존 ○가 페이지 38개 합치기(옛 주소 자동 이동 포함) 여부를 결정하자고 제안 |
| 같은 페이지가 두 주소(`/pages/` 있는 것과 없는 것)로 구글에 잡힘 | 하나로 모으는 작업을 제안 |

## 8. 사람이 직접 확인할 것

- 근거가 약한 랜드마크 5곳: 대전 중동(대전 한의약거리), 천안 사직동(천안희망초등학교), 부산 신창동1가(신창상가), 춘천 요선동(요선시장), 세종 소담동(소담동 행정복지센터). 병한님이 직접 확인 예정.
- 전주 중앙동1가: 동 안에서 확인되는 장소를 찾지 못해 예전 글(팔달로 원도심)이 그대로 남아 있음.

## 9. 지켜야 할 것

- 과장 광고 금지, 금액·결과 단정 금지, 시세·경쟁사 정보 금지.
- 특정 업체명·사업자 정보 전면 노출 금지.
- 확인 안 되는 사실은 넣지 않는다. 빈칸이 지어낸 것보다 낫다.
