# 변경 기록

## 규칙 (2026-10-20 병한님)

- **전환(전화 버튼·문구·폼·첫 화면)에 손대는 변경은 한 번에 하나, 2주 간격.** 날짜·내용·기대 효과·2주 뒤 결과 칸을 채운다. 2주 뒤 결과를 적기 전에는 다음 전환 변경을 하지 않는다.
- **색인·링크·사이트맵 변경은 묶어서 해도 되지만 날짜는 적는다.**
- 매일 루틴이 하는 일(동·구 페이지 생성, 사례 반영)은 적지 않는다. 사람이 하는 세션에서 바꾼 것만 적는다.
- 2주 뒤 결과는 `docs/weekly-check.md` 표의 숫자(① 문의 건수 등)로 적는다.
