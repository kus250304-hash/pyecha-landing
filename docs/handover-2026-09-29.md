## 3. 현재 랜딩페이지 생성 구조

```
data/legal_dong_list.csv ──(pick_next_regions.py, 등록대수 통계 순)──▶ data/batches/YYYY-MM-DD.json (뼈대)
        │                                                     │  사람/루틴이 글 채움 + fact_check 기록
        │                                                     ▼
        │                                  fact_check.py (확인 안 된 장소 이름 찾기)
        │                                                     ▼
        │                     import_batch.py ─ held → data/batches/held/
        │                                    └ confirmed → data/regions.json
        │                                         → build_site.py (pages/*.html, gu/*.html, sitemap.xml)
        │                                         → build_index.py (index.html·thanks.html·privacy.html)
        │                                         → check_pages.py (실패 시 전부 되돌림)
        │                                         → data/fact_checks/YYYY-MM-DD.json
        ▼
커밋 → publish_gate.py 통과 → git push origin HEAD:main → GitHub Actions check + Pages 배포
```

- 페이지 HTML은 손으로 고치지 않는다. 데이터(`regions.json`, `gu.json`, `site_config.json`)를 고치고 다시 렌더링한다.
- 템플릿은 동 페이지 `region-landing-v2.html` 하나, 구 페이지 `gu-landing.html`, 사례 `case.html`.
- 문장 여러 벌(`variants.py`): 소개·공통 FAQ·마무리 각 5벌, 같은 구 안에서 조합이 겹치지 않게 배정.

## 8. 작업할 때 꼭 지킬 것 (CLAUDE.md 요약)

- 금액·시세·경쟁사 금지. "보장·무조건·100%·1위·최저가" 금지. "최고가 도전", "상담 후 확인" 같은 방향 표현은 적극 사용.
- 협력업체 네트워크 고지는 FAQ와 푸터 사이 작은 회색 글씨.
- 모든 동 페이지에 서비스 가능 지역 문구와 출장 방문 안내.
- 장소 이름은 웹 검색으로 **그 동 안에 있다는 근거**를 찾은 것만. 확실하지 않으면 보류. 도로명 랜드마크 금지. 출처 주소를 지어내지 않음.
- 새 이름 사용: 인천 제물포구·영종구·서해구·검단구, 전남광주통합특별시. 기존 slug 는 바꾸지 않음.
- 페이지 HTML·`index.html` 푸터를 손으로 고치지 않음. 주소는 `site_config.json` 한 곳에서만.
- 반영 전 `python3 scripts/check_pages.py` 오류 0건. 사람이 요청한 변경은 PR 없이 main 에 바로 반영하고 보고에 남김.
- 커밋 메시지에 모델 이름을 넣지 않음.
