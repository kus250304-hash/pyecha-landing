## 30초 요약

1. **롱폼 대본 4편을 썼습니다.** 편마다 6~7분, 장면 14~15개이고, 장면마다 [화면](무엇을 찍나)과 [말](병한님이 할 말) 두 줄입니다. 설명란 초안도 편마다 붙어 있어 그대로 들고 찍으시면 됩니다.
2. **찍는 순서는 압류 → 시동 안 걸리는 차 → 폐차값·수출값 → 고쳐 탈까**를 권합니다. 문의가 실제로 찍힌 주제가 먼저입니다. 파일 번호가 곧 찍는 순서입니다.
3. **차 이야기는 깊은 사례 17건에 적힌 사실만 썼습니다.** 금액·약속·단정 표현은 검사해서 0건입니다. **반대 검토(다른 눈으로 거꾸로 따지기)는 지금 돌고 있고, 지적을 고친 판과 `review.md` 를 이어서 올립니다.** 사이트 페이지·스크립트는 하나도 안 바꿨습니다.

쇼츠는 만들지 않았습니다(주간 꾸러미가 매주 4편을 만들고 있어서).

## 편마다 준비물 (찍을 차·서류 장면)

**공통**: 흰 종이 대여섯 장, 굵은 펜, 달력 한 장, 번호판 가림판("폐차 1600-6011" 판). 얼굴은 안 나와도 됩니다 — 손, 뒷모습, 종이에 쓰는 장면으로 짰습니다. 사례 사진은 `cases/images/` 에 있는, 번호판을 이미 가린 사진입니다(파일 이름은 대본 [화면] 줄에 적혀 있음).

### 1편 압류

- 서류: 압류 줄이 여러 개 찍힌 자동차등록원부(화면이나 출력본) — 차번호·차대번호·이름·주민번호·주소 가림
- 서류: 말소증 사진이 온 문자 화면 — 이름·차번호·주소 가림
- 차: 마당에 서 있는 오래된 차 한 대(먼지 낀 앞 유리, 바람 빠진 타이어, 보닛)
- 장면: 견인차에 차가 올라가는 모습 한 번(옆면 상호·전화번호 안 보이게)
- 종이: "차령초과말소 / 승용차 11년 / 1톤 화물차 10년", 조건 두 줄, "차 확인 → 먼저 입금 → 차 출발 → 말소증 문자", "밀린 세금·과태료는 남습니다", 갈림길 그림
- 사례 사진: 구미 쏘나타 1장, 목포 에쿠스 3장, 쌍촌동 포터 2장, 군산 모닝 2장

### 2편 시동 안 걸리는 차·세워 둔 차

- 차: 시동이 안 걸리는 차 한 대(키를 돌려도 조용한 계기판), 먼지·낙엽이 쌓인 바퀴 둘레
- 장면: 견인차 윈치가 차를 끌어올리는 모습, 배터리에 점프선을 무는 손, 견인차가 골목을 빠져나가는 뒷모습
- 장소: 지하주차장 높이 제한 표지, 좁은 골목 입구, 주차장 바닥(동·호수와 다른 차 번호판 안 보이게)
- 서류: 말소증 사진이 도착한 문자 화면 — 이름·차번호·주소 가림
- 종이: "① 자동차세 ② 책임보험 ③ 정기검사", 세 칸("점프하면 걸릴 것 같다 / 고장·사고로 못 움직인다 / 밀린 게 있을 것 같다")
- 사례 사진: 동탄 스파크 밴 2장, 영천 테라칸 3장, 포천 아반떼 2장 (대전 스파크는 사진 없음 — 마당 차 바퀴로 대신)

### 3편 폐차값·수출값

- 차: 마당에 나란히 선 차 두 대(아무 차나), 폐차장 마당 먼 모습
- 장면: 휴대폰으로 차 앞·옆·뒤·계기판을 찍는 손, 전화를 받는 손
- 서류: 말소증의 "수출말소" 글자 부분 — 나머지는 가림
- 종이: 가운데 줄을 긋고 "폐차값(쇠·부품) / 수출값(찾는 나라)", "차종·차 상태·서류", "① 돈은 언제 주나요? ② 말소증은 받나요?", "받은 견적"이라고만 쓴 메모지(숫자 없음)
- 사례 사진: 포천 아반떼 3장, 안산 LF쏘나타 2장, 안동 제네시스 3장, 동해 봉고3 1장

### 4편 고쳐 탈까, 폐차할까

- 서류: 수리 견적서 소품 — 실제 손님 것 말고 빈 양식이나 직접 쓴 종이(상호·이름·전화·금액 가림)
- 차: 오래 탄 차 운전석(닳은 핸들, 주행거리 많은 계기판), 보닛을 연 엔진룸(호스·벨트·라디에이터를 손전등으로)
- 장면: 견적서를 휴대폰으로 찍어 문자로 보내는 손
- 종이: 저울 그림("수리비 / 지금 차값") 세 장(물음표, 수리비가 가벼운 쪽, 수리비가 무거운 쪽), "폐차값 / 수출값 — 고장 난 그대로", "견적서 사진 + 차 번호", 달력에 "검사·보험"
- 사례 사진: 완주 라세티 3장, 순천 쏘렌토 2장, 진천 그랜드체로키 3장, 구미 NF 쏘나타 1장, 영천 테라칸 1장, 성남 SM7 1장

## 찍을 때 꼭 지킬 것

- 금액은 말에도, 자막에도, 종이에도 넣지 않습니다. 과태료 액수도 말하지 않습니다.
- 견인비는 대본의 한 문장("견인비는 따로 없어요") 그대로만 말합니다.
- 어느 차가 수출 쪽이다, 아니다를 잘라 말하지 않습니다. "알아봤더니 이 차는 이쪽이었다"로만 말합니다.
- 차 이야기는 대본에 있는 만큼만 합니다. 기억나는 뒷이야기가 있어도 사례 기록에 없는 것은 덧붙이지 않습니다(손님 나이·형편·이름, 다른 곳 이름 포함).
- 서류·문자 화면은 차번호·차대번호·이름·주민번호·주소가 한 글자도 안 보이게 가립니다. 견인차는 상호·전화번호가 안 보이게 찍습니다.
- 이 네 편은 주제 영상이라 "맨 끝 5초에 지역·차종 한 줄"은 필요 없습니다. 새로 찍은 차 장면을 사례로도 쓰려면 그 차 영상에만 따로 붙입니다.

## 스스로 검사한 것

- **금지 표현**: 사이트 검사에 쓰는 규칙(금액·결과 약속·수출 단정·손님 정보·매매·보험 견인·개인 상담 사정·견인비 표현·본문 금지 낱말)을 네 편 전체(제목·대본·설명란·해시태그)에 돌려 0건.
- **겹치는 문장**: 31자 넘는 줄·문장이 두 편에 똑같이 있는 곳 0건. 더 엄하게 32자 조각으로 봐도 0건(주소와 사례 사진 파일 이름은 뺌). 출구 문장 "차 번호만 주시면 폐차값·수출값 둘 다 알려드려요"는 27자라 네 편에 그대로 둡니다.
- **사례 대조**: 대본의 차 이야기를 `cases/index.json` 의 걱정·확인·이유·날짜·끝한줄 칸과 한 줄씩 맞대어 봤습니다. 편마다 맨 위 표에 어느 칸을 썼는지 적어 두었습니다.
- **반대 검토**: 아직 반영 전입니다(이 판은 반영 전 판). 끝나면 `review.md` 에 지적과 처리를 적습니다.

## 못 한 것·알아 둘 것

- 업무위키의 `마케팅\콘텐츠원칙.md` 는 PC에만 있어 읽지 못했습니다. `CLAUDE.md` 에 적힌 순서(본능 → 반박 3개 → 선택지 → 출구)를 따랐습니다.
