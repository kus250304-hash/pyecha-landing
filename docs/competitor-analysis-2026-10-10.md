## 3. 정리

### 우리가 없는 것
1. **대표 이미지(og:image)**: 세 곳 모두 1200×630(또는 675) 이미지에 `{지역} {키워드}`와 전화번호를 크게 넣었다. 우리는 동·구 페이지 모두 없다. 네이버·카톡 공유와 검색 미리보기에 그림이 안 뜬다.
2. **본문 이미지**: 경쟁 글은 이미지 8~12장, 우리 용해동 페이지는 0장이다(사례가 붙은 페이지만 사진이 있음).
3. **더 긴 본문**: bestcarwaste·bestpyecha 4,600~5,300자, 우리 동 페이지 3,363자. 다만 늘어난 분량은 거의 지역과 무관한 일반 설명이다.
4. **동 소개에 주변 시설 여러 개**: 경쟁 글 끝의 "용해동 소개"는 맞닿은 동 5곳과 문화회관·산·둘레길·파출소 이름을 나열한다. 우리는 랜드마크 하나 + 설명 1~2문장이다(우리는 이름마다 사실 확인을 거친다).
5. **글 형식의 날짜**: 경쟁은 datePublished·dateModified 둘 다 있고 글 위에 날짜를 보인다. 우리는 dateModified 와 "최종 업데이트"만 있다.
6. **검색 순위**: 두 검색어 모두 1쪽에 없다(경쟁은 1~4위·7·10~13위).

### 우리가 더 나은 것
1. **지역 내용이 진짜 다르고 확인됨**: 랜드마크·지역 FAQ를 웹 검색으로 확인한다. 경쟁의 동 소개는 자동 수집으로 보이고, 본문은 동 이름만 바꾼 일반 설명이다.
2. **지역 구조 링크**: 동 → 목포시 → 전남광주로 경로가 이어지고, 같은 구의 다른 동끼리 연결된다. 경쟁은 동에서 시로 가는 링크가 없거나(infoscrap 경로 줄은 글자뿐), 시 페이지 끝에 **전국 무작위 동**을 건다(bestcarwaste·bestpyecha).
3. **최근 갱신**: 우리는 10월에도 매일 갱신한다. 세 곳 모두 8월 이후 새 글이 0건이다.
4. **번호 하나로 일관**: 1600-6011 + 문자 010-9926-7779. infoscrap 은 페이지 번호와 이미지 번호가 다르다.
5. **실제 사례·영상·블로그**: 목포시 페이지에 실제 사례(싼타페)가 있고 블로그·유튜브로 이어진다. 경쟁은 사례도 블로그 병행도 없다.
6. **정상 canonical·한 도메인**: infoscrap 은 canonical 이 접속 안 되는 도메인을 가리키고, best 계열은 같은 글을 세 도메인에 나눠 둔다. 우리는 한 주소 한 페이지다.
7. **과장 없음·개인정보 동의 안내**: 이미지·본문 모두 단정 표현이 없고, 폼마다 개인정보처리방침 동의 안내가 있다.

### 따라 하면 안 되는 것
1. **키워드 × 동 글 24개씩 만들기**: 같은 운영으로 보이는 세 도메인에 용해동 글 72개가 있다. 동 이름과 키워드만 바꾼 복제 글이라 어뷰징으로 볼 위험이 크다(roadmap 11절 "안 하는 것"과 같음).
2. **같은 글을 여러 도메인에 두기**: bestpyecha·bestcarwaste·bestpyechajang 의 같은 구조 글, infoscrap ↔ 동네폐차장.kr canonical.
3. **canonical 을 다른(또는 죽은) 도메인으로 걸기**: 검색엔진이 그 페이지를 원본으로 보지 않게 된다.
4. **이미지에 확인 안 된 문구 넣기**: "정부허가 업체", "무료상담·당일견인", 실제가 아닌 그림, 페이지와 다른 전화번호. 대표 이미지를 만들 때도 지역 이름·`폐차장 · 폐차`·대표번호만 넣고, 과장·단정 문구와 AI 생성 장면은 쓰지 않는다.
5. **시 페이지에 상관없는 지역 링크 걸기**: 목포시 페이지 끝의 전국 무작위 동 링크는 이용자에게도 검색엔진에도 지역 구조를 흐린다.
6. **금액 이야기를 길게 늘이기**: 경쟁 본문 상당 부분이 고철가·잔존가·감가 설명이다. 우리는 금액을 "상담 후 확인"으로 두고 `/guide/` "폐차 금액" 한 장에만 일반 설명을 둔다.

## 4. 다음에 검토할 것 (이 문서는 기록만, 반영은 따로 결정)
- 동·구 페이지 대표 이미지(og:image) 자동 생성: `{지역} 폐차장 · 폐차` + 1600-6011, 실제 사진 또는 단색 배경, 과장 문구 없음.
- 동 페이지 본문 이미지: 같은 구 사례 사진이나 실제 현장 사진 1~2장.

- 용해동·목포시 검색 순위를 2주 뒤 다시 확인(서치어드바이저 노출 숫자와 함께).
