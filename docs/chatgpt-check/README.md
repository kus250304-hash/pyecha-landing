# 챗GPT 검사 대기 칸 (2026-11-19 병한님 "4")

사이트 문구를 바꾸는 묶음은 넣기 전에 챗GPT 로 교차 검증합니다(`docs/current-rules.md`). 병한님이 따로 기억하지 않도록 **일요일 발행판**에 같이 나옵니다.

- `대기.md` 가 있으면 = 검사를 기다리는 한 장이 있다는 뜻입니다. 클로드가 만들 묶음이 생기면 여기에 넣습니다(한 번에 하나).
- 일요일 발행판(업무위키 `_도구\주간꾸러미.py`, 토요일 밤 9시)이 이 파일을 읽어 **맨 위**에 "챗GPT 검사" 칸으로 보입니다.
- 병한님: 그 칸의 코드 상자를 복사 → 챗GPT 에 붙여 넣기 → 챗GPT 답을 클로드 채팅에 붙여 넣기. 이것뿐입니다.
- 클로드: 답을 받아 고치고 묶음을 넣은 뒤 `대기.md` 를 지웁니다(지우면 다음 발행판에서 칸이 사라짐). 넣은 날부터 2주는 문구를 바꾸지 않습니다.
- 손으로 고치지 않습니다.
